# PRサマリー本文編集

## コンテキスト

### PR情報
PRの基本情報を取得:
!`gh pr view $ARGUMENTS --json title,body,author,baseRefName,headRefName,additions,deletions,changedFiles`

### 変更ファイル一覧
!`gh pr diff $ARGUMENTS --name-only`

### 変更差分
!`gh pr diff $ARGUMENTS`

## タスク

上記の情報を元に、以下の形式でPRの変更内容をまとめたサマリーを作成し、PR本文を編集して追記・更新してください。

### サマリーのフォーマット

```markdown
## 📝 PR変更サマリー

### 概要
[この PR で行われた変更の簡潔な説明 - 2〜3文程度]

### 主な変更点
- [変更点1]
- [変更点2]
- [変更点3]
...

### 変更ファイル
| ファイル | 変更種別 | 説明 |
|---------|---------|------|
| [ファイルパス] | [追加/修正/削除] | [変更内容の簡潔な説明] |
...

### 影響範囲
[この変更が影響する可能性のある箇所やコンポーネント]

### レビューポイント
[レビュー時に特に注目すべき点があれば記載]

---
*このサマリーは自動生成されました*
```

### PR本文編集手順

1. 上記のフォーマットに従ってサマリーを作成
2. 現在のPR本文を取得:
   ```bash
   gh pr view $ARGUMENTS --json body -q .body
   ```
3. セパレータの確認と本文の組み立て:
   - セパレータは以下のテキスト:
     ```
     ---
     以下AI生成PRサマリー
     ```
   - **PR本文にセパレータが既に存在する場合**: セパレータより上のテキストをそのまま保持し、セパレータ以降（セパレータ自体を含む）を削除して、セパレータ + 生成したサマリーに置換する
   - **PR本文にセパレータが存在しない場合**: 既存のPR本文の末尾にセパレータを追記し、その下に生成したサマリーを追記する
4. 組み立てた新しいPR本文で更新:
   ```bash
   gh pr edit $ARGUMENTS --body "<組み立てた新しいPR本文>"
   ```

### 注意事項

- 変更内容を正確に把握し、技術的な詳細を適切にまとめてください
- 日本語で記述してください
- コードの意図や目的を理解した上でサマリーを作成してください
- セキュリティに関わる変更がある場合は、レビューポイントで明示してください
- セパレータより上の既存PR本文は絶対に変更しないでください
